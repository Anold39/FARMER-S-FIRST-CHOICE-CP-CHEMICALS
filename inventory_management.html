Bulk Update via CSV

Upload a CSV with the header row name,category,unitSize,price,stock,description,keywords. Rows matching an existing product name update its price/stock (and category/unitSize/description if provided); rows with a new name are added as new products. name, price and stock are required columns.

Diagnostic keywords: the keywords column controls which farmer-typed symptoms the AI Advisory Portal will match to this product (e.g. yellow leaves;chlorosis;pale plant — separate multiple terms with a semicolon, not a comma). Uploading new keywords for an existing product adds them to what's already there; it never deletes existing keywords, so a routine price update won't accidentally break the AI's matching for that product. This is how new symptoms can be taught to the AI Advisory Portal without editing any code.
